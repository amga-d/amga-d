## 🧑‍💻 About Me

- 🎯 **Main focus:** DevOps, system administration and cloud engineering
- 🐧 Administering **Ubuntu/Linux** systems and automating them with **Bash**
- 🖥️ Virtualization with **KVM/QEMU**; containers with **Docker**
- ☸️ Learning **Kubernetes** and **GitOps** delivery with **Argo CD**
- 📈 Infrastructure monitoring (Nagios + Docker Compose)
- ⚙️ **Backend engineering:** REST APIs and web backends with Node.js/Express, PHP/Laravel and MySQL/MongoDB
- 🤖 **Data & AI/ML:** data analysis and dashboards, plus ML models such as YOLO (Ultralytics) and on-device LLMs
- 🌐 Full-stack apps with TypeScript, React and Next.js
- 🎓 Student at **Universitas Islam Indonesia**, based in Indonesia
